====================================================================================================
INTERPRETAÇÃO PRELIMINAR
====================================================================================================
Este relatório é estatístico.

Nenhum byte é automaticamente classificado como opcode.

A presença de padrões repetidos pode indicar cabeçalhos, IDs, flags, tipos ou estruturas, mas isso precisa ser confirmado por capturas diferenciais.

Entropia alta pode indicar compressão, criptografia ou simplesmente dados binários com distribuição relativamente uniforme.

Payloads UDP devem ser analisados respeitando as fronteiras dos datagramas.

Para TCP, a fronteira dos pacotes capturados não necessariamente corresponde à fronteira das mensagens da aplicação.

O próximo passo recomendado é correlacionar ações específicas no cliente com alterações específicas nos pacotes.

Exemplo:
  CAPTURA A = conectar + ficar parado
  CAPTURA B = conectar + executar ação X
  diferença A/B = candidatos relacionados a X
